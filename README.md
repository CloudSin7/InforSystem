# InforSystem
 仿照学校信息门户书写的JavaSpringBoot+React项目
前端是React项目，在Font/information-portal1路径运行命令行输入npm start开启前端服务器运行（如果遇到问题，先删除node_modules文件夹，再install，然后start）
后端是Idea的Java，使用Spring框架，本地使用Idea打开后开启后端服务，部署服务器可打开后进行打包再部署

项目功能：
1.基础的人员信息管理：仿照企业后端管理员的页面，提供后台管理员按学院、部门查看人员信息并进行增删查改的功能
2.信息隔离：学校部分通知只用于给老师看，所以根据学生/老师的用户身份添加隔离，主页展示的通知都是“应该看到的通知”
3.信息分类展示：仿照学校将通知分为学工、科研、教学等4类，动态根据需要展示的信息数量在前端进行分类展示
4.站内信：类似邮箱，每个用户都可以对其他用户收发信件，需要添加用户身份检查避免权限问题
